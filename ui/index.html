More about website access

Browser requests without an Origin header are rejected. When local scripts are off, only approved websites may use the API. When on, clients that send neither Origin nor browser fetch metadata (for example curl) can print without website approval. Denied websites stay denied until removed.

Recent prints

Keeps the last 50 print jobs in memory (payload preview up to 20 KB). Shows HTTP print calls (/, /write, /convert) and in-app test prints. Virtual printer jobs are listed even when capture is off.
