First label

BrowserPrint drop-in. Turn Compatible mode on in Settings. If this page says the script is missing, run npm run build:browserprint and reload.

  1. Launch RawLabelPrint (menu bar / system tray icon).
  2. Search or add the printer, save it, and set it as the default. A search result is not printable until it is saved.
  3. Serve this repo from the root and open this page. A file:// URL still needs approval and is easy to miss. 
    python3 -m http.server 8080
    Then open http://127.0.0.1:8080/test/quickstart-browserprint.html.
  4. The first request appears under Allowed websites. Approve http://127.0.0.1:8080 and send again.
